# LitBuild

Mod cliente para Minecraft 1.12.2 con LiteLoader, inspirado en la funcionalidad de Axiom (reimplementación propia a partir de su documentación pública, ver `docs/`). La interfaz usa Dear ImGui (imgui-java) con un backend propio para LWJGL 2.

## Compilar e instalar

Requiere Java 8 (el wrapper de Gradle es 4.9, que no corre en Java 17):

```sh
export JAVA_HOME=/usr/lib/jvm/java-8-openjdk
./gradlew installMod
```

Compila, reofusca y copia `mod-litbuild-*.litemod` a la instancia de Prism indicada en `gradle.properties` (`prismInstance`, por defecto `axiom-dev`).

## Probar

Abrir la instancia `axiom-dev` en Prism, entrar en un mundo de un jugador y pulsar **Right Shift** para abrir el editor. Escape o Right Shift lo cierran.
En `.minecraft/logs/latest.log` debe aparecer `LitBuild cargado` e `imgui-java: librería nativa cargada`.

### Interfaz

- Diseño por defecto con docking: herramientas, selección, bloque activo y portapapeles a la izquierda (en pestañas); opciones de herramienta y máscaras arriba a la derecha; información (Target Info, World Properties, History...) abajo a la derecha. El centro deja pasar el ratón al mundo. Las ventanas se pueden arrastrar y acoplar a otro sitio.
- Barra de estado inferior: herramienta activa, tamaño de la selección, último mensaje y FPS.
- Menú **View**: *Theme* (Axiom Dark, Light, Classic, ImGui Dark), *UI size* (tamaño de la fuente, 12-28 px) y *Reset layout* (vuelve a la disposición por defecto). Se recuerdan en `config/litbuild/ui.properties`.

### Selector de bloques e iconos

- Cada campo de bloque (Active Block, Replace, Noise Painter, Tool Masks) tiene un **icono de inventario**: púlsalo para abrir el *Block Picker*, una cuadrícula de todos los bloques del inventario creativo con búsqueda, filtro por pestaña creativa y los últimos usados. Elegir uno escribe su id y su meta en el campo (con Ctrl pulsado la ventana no se cierra). El id y la meta también se pueden escribir a mano.
- Los iconos de bloques se dibujan a partir del modelo del propio juego con su vista isométrica de inventario (incluye escaleras, losas, vallas...), con el tinte de hierba y hojas aproximado. Los bloques con renderizado especial (cofres, camas, cabezas) usan su textura plana.
- La ventana **Tools** es una cuadrícula de iconos vectoriales (tooltip con el nombre y el atajo); las formas de Shape y las del pincel se eligen con iconos.

### Controles del editor

| Acción | Entrada |
|---|---|
| Girar la cámara | Arrastrar con el botón izquierdo sobre el mundo |
| Moverse / volar | W A S D, Espacio, Shift (vuelo creativo: doble Espacio) |
| Box Select | Botón derecho: clic en un bloque y arrastrar hasta otro. Se ajusta con los campos Pos 1 / Pos 2 de la ventana Selection |
| Copiar bloque a Active Block | Clic central sobre un bloque (o escribir el id y la meta) |
| Manejadores de Box Select | Con Box Select y una selección en caja aparece un cubito de color en el centro de cada cara (rojo X, verde Y, azul Z). Arrástralo con el **botón izquierdo** para estirar o encoger esa cara; no puede cruzar a la opuesta (queda al menos 1 bloque). Se mide sobre la dirección del eje en pantalla, así que da igual desde dónde mires, salvo que el eje apunte directo a la cámara. No aparecen con selecciones de Magic Select |
| Altura / tamaño de la selección | Ventana Selection: Amount + botones Up, Down, North, South, West, East estiran esa cara (con Shrink la encogen); Full height la lleva de Y 0 a 255. Atajos: RePág / AvPág estiran hacia arriba / abajo (con Shift la encogen) |
| Elegir herramienta | Ventana Tools, o B (Box Select), M (Magic Select), P (Painter), O (Noise Painter), G (Freehand Draw) |
| Magic Select | Botón derecho sobre un bloque: selecciona por relleno los conectados. Opciones: Compare (Block, BlockState, Solid, Any), Limit, Range (salta huecos), Corners, Surface Only y Mode (Replace, Add, Subtract, Intersect). La selección resultante no es una caja: todas las operaciones respetan su forma |
| Noise Painter | Lista de bloques con peso, Scale, Octaves, Seed, 3D y White noise. Los pesos se cumplen como porcentajes del volumen pintado. Mantén el botón derecho |
| Smooth / Melt / Weld | Teclas U / K / J. Desenfoque gaussiano del terreno dentro del pincel: Smooth conserva el nº de bloques (Block ratio 100 %), Melt quita masa en salientes y Weld rellena zonas cóncavas con el Active Block. Opciones: Radius (máx. 16), Shape, Strength (1-4) y Block ratio. Mantén el botón derecho |
| Elevation | Tecla E. Sube, baja o aplana (Mode) el terreno por columnas dentro del círculo del pincel; el efecto es máximo en el centro y se acumula al arrastrar. Opciones: Radius (máx. 16), Mode y Amount |
| Distort | Deforma el terreno con ruido (Scale, Distance, Seed): cada bloque pasa a ser el que hay en una posición desplazada. Mantén el botón derecho |
| Text | Escribe un texto con el Active Block usando una fuente de Java (SansSerif, Serif, Monospaced, Dialog; tamaño, negrita, cursiva). *Create Placement* lo coloca como un pegado; de pie se lee desde el sur (Ctrl+R lo gira) y con *Flat* queda tumbado |
| Script Brush | Pincel programable en **Lua** (LuaJ). El script corre por cada bloque del pincel con sus coordenadas `x, y, z`; si devuelve un id de bloque (`blocks.stone`, `blocks["dirt:1"]`...) se coloca ahí. Con `$once$` corre una sola vez por sello. Las variables de plantilla `$int(Título, valor, mín, máx)$`, `$float(...)$`, `$boolean(Título, valor)$` y `$blockState(Título, minecraft:stone)$` generan controles solas. Funciones: `getBlock`, `getBlockState`, `setBlock`, `isSolid`, `getHighestBlockYAt`, `withBlockProperty`, `getBlockProperty`, `isBlockTagged`, `getBlockRGB`, `findClosestBlockToRGB`, `getSimplexNoise`, `getVoroniEdgeNoise` y `print`. Hay tres ejemplos y un botón *Check syntax*. Corre aislado (sin `io`, `os`, `load` ni `require`) y cada sello tiene un presupuesto de 10 M de instrucciones, que corta los bucles infinitos. Diferencias con Axiom por ser 1.12: un id de estado es `id_del_bloque * 16 + meta`, `blocks.xxx` usa los nombres de 1.12 (con algunos alias de los nuevos como `coarse_dirt` o `oak_planks`) y los *tags* se aproximan por clase o nombre del bloque |
| Gradient Painter | Pinta bloques sólidos repartiendo una lista de bloques (con pesos = tamaño de banda) a lo largo de una dirección (±X, ±Y, ±Z) o desde un punto (*Spherical*). Interpolación *Nearest* (bandas), *Linear* o *Bezier* (las transiciones se mezclan con ruido blanco), *Clamp* y *Length*. El origen es el primer bloque del trazo o uno fijo (Ctrl + botón derecho) |
| Freehand Select | Selección pintando con un pincel (radio y forma): los bloques bajo el pincel se suman a la selección en vivo; modos Replace / Add / Subtract / Intersect y *Solid blocks only* |
| Stamp | Copia el portapapeles a lo largo de un trazo cada *Spacing* bloques, con *Scatter*, *Chance*, giro y volteo al azar, *Drop* y *Keep Existing*, apoyado en la superficie. Pensado para bosques y rocas. No copia tile entities |
| Lasso Select (L) | Mantén el botón derecho y dibuja un bucle en pantalla: al soltar se lanzan rayos desde una rejilla de píxeles dentro del contorno (hasta 30 000) y los bloques visibles pasan a la selección según el modo (Replace / Add / Subtract / Intersect). *Depth* los extiende hacia dentro de la vista e *Include Non-Solid* cuenta también hierba y flores. En lazos muy grandes los bloques lejanos pueden quedar con huecos |
| Sculpt Draw | Levanta una protuberancia siguiendo la **normal de la superficie** (la dirección del aire dentro del pincel) o siempre hacia arriba con *Mask Y*; *Invert* la hunde. *Strength* (logarítmica, 0,05–5) escala la altura y *Denoise* desenfoca el campo para una forma más lisa. No usa el Active Block: los bloques nuevos copian a sus vecinos (la hierba tapada pasa a tierra). Acumulativo dentro del trazo |
| Slope | 1) Botón derecho en un bloque fija el **objetivo** (caja magenta). 2) Mantén el botón derecho desde otro bloque y arrastra: el terreno se lleva a la recta inicio-objetivo. La barra de estado muestra la diferencia de altura, el ángulo y la distancia. *Plane* (rampa) o *Cone* (pendiente radial alrededor del inicio: cuenco si el objetivo está arriba, montículo si está abajo). *Height* limita el cambio por columna y *Sharpness* lo rápido que llega al 100 % desde el borde. Ctrl + clic fija otro objetivo; *Clear target* lo quita. No usa simetría |
| Modify | Transforma la selección con *Apply* (se deshace con Ctrl+Z). **Translate Copies**: Count copias con un desplazamiento (relativo al tamaño de la selección o absoluto). **Rotate Copies**: Count copias giradas alrededor de un eje (X/Y/Z) que pasa por el pivote, *Equidistant* (360° / (Count+1)) o *Custom Angle*, con *Add Translation* para la espiral. **Revolve**: enrolla la selección en un arco (su longitud es el ángulo y su profundidad el radio desde *Inner radius*; *Angle* hasta 360°, *Add Translation* para una espiral; *Remove original*). **Twist**: gira cada capa más que la anterior (*Angle* es el giro total de abajo a arriba). El pivote es el centro de la selección o un bloque fijado con Ctrl + botón derecho (caja amarilla). Todo se calcula por muestreo inverso, sin huecos; con el eje Y los bloques con orientación giran en cuartos de vuelta y no se copian los tile entities |
| Modelling | Puntos 3D que forman superficies, agrupados en filas: botón derecho añade un punto a la fila actual (*Offset target point* lo pone en el bloque contiguo a la cara apuntada), *New row*, *Remove last*, *Clear* y la lista *Points* para editar sus coordenadas. *Shape*: **Loft** (une filas contiguas punto a punto; *Surface*: Flat, Catmull-Rom que pasa por todos los puntos o Bezier que aproxima), **Triangle Strip**, **Triangle Fan** y **Convex Hull** (la superficie del casco). *Build* voxeliza la superficie con el Active Block (muestreo cada 0,35 bloques, sin huecos) y la deja como Placement en su sitio, listo para confirmar con Enter. **E** duplica el último punto (contextual: no choca con Elevation). **Smart Surface** (en *Surface* de Loft) ignora las filas: proyecta todos los puntos en el plano de sus dos ejes más largos, los triangula con Delaunay y rellena cada triángulo en 3D, así que la superficie sigue la altura de cada punto (hacen falta 3 puntos que no estén en línea) |
| Reference Image | File > *Open Reference Image...* (o Window): ventana flotante con una imagen por URL o ruta de archivo; la carga va en segundo plano. Clic derecho en la ventana: *Close Window*, *Filtering: Nearest*, **Show In Game UI** (la imagen sigue sobre el juego, en el mismo sitio y tamaño, con el editor cerrado), **Borderless** y *Opacity* |
| Annotation | Dibuja sobre el terreno para planificar. *Mode*: **Draw** (línea pegada a la superficie con botón derecho arrastrando, *Width*), **Outline** (*Freehand*: resalta los bloques por los que pasas; *Box*: entre dos bloques resalta todos los que no son aire, hasta 5000), **Text** (texto flotante con *Shadow*; se ve con el editor abierto y se edita, se visita o se borra en Window > Text Annotations) y **Erase** (borra lo que queda dentro de *Radius*). *Color* con selector. Tiene su propio deshacer: con la herramienta activa, Ctrl+Z y Ctrl+Y actúan sobre las anotaciones. Se guardan por mundo en `saves/<mundo>/litbuild-annotations.txt`; *View > Show Annotations* las oculta y *Clear ALL Annotations* las borra (sin deshacer). Los modos **Image** (pega una imagen por URL http/https o ruta de archivo, con *Width*, de cara a la superficie; si no carga se ve una textura rosa y negra) y **Move** (arrastra el texto o la imagen más cercana, a menos de 4 bloques, a otra superficie) también entran en el deshacer propio |
| Fluid Ball | Mantén el botón derecho para colocar una esfera de **Water** o **Lava** o de **Snow** (capas sobre la superficie, más gruesas en el centro). Con agua o lava: *Infinite Sources* (la región inicial es toda de fuentes; desactivado, es una sola fuente en el centro), **Flow Length** (0-7: cuántos bloques se extiende el fluido en horizontal desde las fuentes, bajando un nivel por bloque —dos la lava— y cayendo por los huecos hasta que algo lo frena; 0 = solo las fuentes), **Require Support To Flow** (solo fluye sobre bloques sólidos: sin cascadas) y **Remove Fluids Without Sources** (quita el agua o lava que fluye alrededor antes de colocar la nueva). El flujo se calcula de antemano con las reglas de vanilla y luego el juego lo sigue simulando; Ctrl+Z quita todo lo colocado. **Fill Edges** rellena las esquinas sueltas de la orilla (celdas rodeadas de fluido y pared) y, si el fluido llena un recipiente cerrado que contiene una fuente, lo deja plano: todo fuentes. **Quality** (1-3): 1 extiende solo en cuatro direcciones (el rombo de vanilla), 2 añade las diagonales y 3 los saltos de caballo, y el nivel sale de la distancia recorrida, así que la mancha sale más redonda; el juego sigue simulando el fluido después de colocarlo y puede retocar los niveles |
| Biome Painter | Mantén el botón derecho para pintar un bioma (lista alfabética) con el radio del pincel. En 1.12 el bioma es por columna, así que siempre se pinta la columna entera (*Fill Vertically*) y cambia el color de hierba, hojas y agua; el servidor reenvía los chunks para que se repinten. Entra en el historial y se deshace con Ctrl+Z. **Visualize Biome** (casilla) pinta de colores los biomas del terreno de alrededor mientras la herramienta está activa; View > *Show Biomes* (Ctrl+B) lo deja siempre. El color es el bioma real de la columna, no el degradado de hierba y agua del juego |
| Roughen | Lo contrario de Smooth: deja el terreno dentado conservando el número de bloques. Opciones: Radius (máx. 16), Shape, Strength, Roughness y Seed. Mantén el botón derecho |
| Shatter | Abre grietas tipo Voronoi en los bloques sólidos dentro del pincel, o las rellena con el Active Block (*Fill cracks*). *Scale* es la distancia típica entre grietas y *Width* su grosor: con Scale pequeña y Width grande se rompe casi todo |
| Rock | Botón derecho coloca una roca irregular (esfera deformada por ruido) con el Active Block, medio hundida en el terreno. Radius, Noisiness, Noise scale y Seed (aleatoria por defecto). Una edición por roca |
| Floodfill | Botón derecho sobre una cara rellena con el Active Block el hueco conectado (aire, agua, plantas...) avanzando en horizontal, hacia abajo y/o arriba según los permisos, con un Limit de bloques |
| Path | Botón derecho añade nodos; *Line* los une con rectas, *Catmull-Rom* con una curva que pasa por todos y *Bezier* con una curva que solo toca el primero y el último. Radius 0-8, *Looped* y *Keep Existing*. Se ve la curva en el mundo; *Apply* la coloca con el Active Block |
| Views | Ventana Views: guarda la posición y la mirada actuales con un nombre y vuelve a ella con *Go* (misma dimensión). Se guardan en `config/litbuild/views.properties` |
| Inventory | Ventana Inventory: tu inventario con iconos; un clic en un bloque lo copia al Active Block |
| Symmetry | Botón derecho coloca el **nodo** en el punto exacto que apuntas (cara, arista o vértice). Con *Enabled*, los pinceles también se aplican en las posiciones reflejadas (Mirror X/Y/Z) o giradas 180° o 90° alrededor del nodo. Se dibujan el nodo y los planos de espejo |
| Operaciones nuevas | Operations > *Simulate Gravity* (los bloques de cada columna de la caja caen conservando su orden hasta apoyarse en el primer bloque sólido que haya bajo la caja), *Fill Gaps* (rellena con el Active Block el espacio no sólido al que no se llega desde fuera) y *Type Replace* (con un Active Block de la misma clase, p. ej. unas escaleras, sustituye las de la selección conservando orientación y mitad). Las dos primeras solo con selección en caja |
| Jugador | World Properties > Player: velocidad de vuelo (100-999 %), **No Clip**, **Invulnerable**, **Block gravity** (desactivado, la arena y la grava no caen), **Trample farmland** (desactivado, no se pisa la tierra de cultivo; sigue el daño por caída), **Block drops** (la regla `doTileDrops`) y botones de modo de juego (necesitan permisos de comandos) |
| View | *Show Biomes* (Ctrl+B, reasignable), *Fluid Opacity* (0-1; cambia el alfa de las texturas del **agua**, quieta y en movimiento, en el atlas de bloques, y *Reset Fluid Opacity* vuelve al de vanilla; se guarda), *Min Brightness* (0-1; sube el gamma del juego, también fuera del editor, y apunta el original en `config/litbuild/gamma.txt` por si el juego guarda el gamma alto: al arrancar se restaura) *Show Annotations*, *Show Selections*, *Show Ruler*, *Show Key Presses* e *Invert Camera Rotate*; Window > **Style Editor** (el editor de estilo de ImGui; los cambios no se guardan) |
| No Clip | Casilla en World Properties > Player (o la tecla *Alternar No Clip* de Controles, sin asignar por defecto): el jugador atraviesa bloques, sin asfixia ni la textura del bloque tapando la pantalla. Fuerza el vuelo, así que hay que estar en creativo (sin poder volar caerías por el suelo). Funciona con mixins sobre `Entity.move`, `pushOutOfBlocks` e `isEntityInsideOpaqueBlock`; si no se aplican, el juego sigue normal y la ventana avisa de que no ha actuado |
| Extrude | Tecla Z. Botón derecho sobre una cara: la superficie de bloques iguales (según Compare) crece hacia fuera N capas; con Shrink o Shift se come capas |
| Ruler | Botón derecho añade puntos; en Tool Options: distancia euclídea y Manhattan, tamaño de la caja que los contiene, yaw/pitch con 2 puntos y *Select bounds* (convierte los puntos en una selección) |
| Tool Masks | Window > Tool Masks. Reglas (Block, Above, Below, Surface, Can See Sky, In Selection, Y, Neighbour, Adjacent), cada una con NOT; deben cumplirse todas. Restringen Painter, Noise Painter, Freehand Draw, Smooth, Melt y Weld |
| History | Window > History: lista de ediciones; pulsar una deshace (o rehace) hasta ella |
| Move / Stack | Ventana Move / Stack (con selección): Move desplaza el contenido y la selección; Stack repite N copias en una dirección con una separación (Gap). Una sola edición deshacible |
| Schematics | File > Schematics...: *Export clipboard* guarda el portapapeles en `config/litbuild/schematics` en tres formatos a elegir: **Schematic** (`.schematic`, MCEdit/WorldEdit clásico), **Sponge** (`.schem`, v2; se leen también v1 y v3) y **Structure NBT** (`.nbt`, el de los structure blocks). *Import* detecta el formato por la extensión y lo carga como Placement; los bloques que no existen en 1.12 (de archivos de versiones nuevas) entran como aire y se avisa de cuántos |
| Exportar la selección | File > *Export Selection as Sponge (.schem)*, *Export Selection as Structure NBT* y *Save Selection as CSV* (`x,y,z,bloque` de los bloques no aire) guardan la selección con su máscara en la carpeta de schematics, con nombre `selection-<fecha>`. No hace falta copiarla antes |
| Shape (selección) | Selection > *Shape*, y Select > *Bounding Box*: cambian la forma de la selección sin tocar bloques. **Bounding Box** (de máscara a caja), **Filter** (se queda con un bloque, con o sin meta), **Smooth** (desenfoque gaussiano de la forma: *StdDev* y *Threshold*; redondea esquinas y rellena agujeros interiores), **Distort** (ruido: *Radius*, *Distance*, *Seed*) y **Move selection** (solo la selección, no los bloques). Todo entra en una sola selección de máscara; no se deshace con Ctrl+Z (la selección no es una edición del mundo) |
| Painter / Freehand Draw | Ventana Tool Options: Radius, Shape (Sphere/Cube/Octahedron) y, en Painter, Mask Surface. Mantén el botón derecho sobre el mundo y arrastra: pinta con el Active Block (Painter solo cambia bloques sólidos; Freehand Draw rellena todo el volumen). Un trazo entero se deshace de una vez |
| Shape | Tool Options: tipo (Sphere, Cuboid, Cylinder, Cone, Pyramid, Octahedron, Disk), tamaño X Y Z y Hollow; *Create Placement* genera la forma con el Active Block y se coloca como un pegado |
| Operations | Fill, Fill Outline/Walls/Shell/Top/Bottom, Replace, Hollow, Drain (quita agua y lava), Analyze (cuenta bloques de la selección), Delete |
| Fill Nearest, Set Biome, Smoothsnow, Trigger Updates | Operations (y ventana Selection > *More operations*). **Fill Nearest**: cada bloque de aire de la selección toma el estado del bloque no aire más cercano de la selección. **Set Biome**: cambia el bioma de todas las columnas de la selección (en 1.12 es por columna) y se deshace con Ctrl+Z. **Smoothsnow**: capas de nieve (*Max layers* 1-8) sobre la superficie de cada columna; la altura sigue una media del terreno en *Smooth radius*, así que huecos y escalones se rellenan con más capas y la cobertura es continua; solo ocupa aire y plantas bajas, y repetirla no acumula. **Trigger Updates**: avisa a cada bloque de que sus vecinos cambiaron y desaparecen los que no pueden sostenerse (carteles o antorchas flotantes), sin soltar objetos; ignora fluidos y bloques con gravedad, y lo que se rompa en cadena fuera de la selección no entra en el historial |
| Tool Presets | Al final de Tool Options (y de la ventana Tool Masks): *Presets* guarda los ajustes de la herramienta con un nombre (*Save preset*; si el nombre ya existe lo sustituye), y cada preset tiene *Load* y *X* para borrarlo. Valen para Painter, Noise Painter, Freehand Draw, Smooth, Melt, Weld, Elevation, Distort, Roughen, Shatter, Rock, Script Brush (con su código Lua), Gradient Painter, Sculpt Draw, Slope, Stamp, Fluid Ball, Floodfill, Path, Extrude, Magic Select, Text, Shape, Lasso y Freehand Select, además de Tool Masks (con sus reglas). Noise y Gradient guardan también la lista de bloques con sus pesos. Se guardan por herramienta en `config/litbuild/presets/<herramienta>.txt`. No entran el Active Block, la selección ni los bloques de variantes del Stamp; Modify, Biome Painter y Annotation no tienen presets todavía |
| Keybinds | Window > *Keybinds*: todos los atajos del editor son reasignables (*Set*, luego la tecla, con Ctrl o Shift si los quieres; Esc cancela) y se guardan en `config/litbuild/keybinds.properties`. Son: Undo, Redo, Copy, Cut, Paste, Delete, Save Blueprint, Quick Fill, Quick Replace, los de Placement (confirmar, cancelar, rotar, voltear), **Swap To Last Tool** (sin tecla por defecto) y una tecla por herramienta (las de Axiom por defecto: B, M, N, L, P, O, G, U, K, J, Z, E, H). Los que chocan con otro del mismo contexto salen en rojo (Ctrl+F y Ctrl+R sirven a la vez para Fill/Replace y Flip/Rotate porque uno es del Placement). Fijos: flechas y RePág/AvPág, Backspace en el Placement, clic central, Escape y Right Shift. Con esto *Elevation* (E) y *Rock* (H) ya responden a su tecla |
| Builder Mode | Lo que se usa **en el mundo, sin abrir el editor** (solo en un mundo de un jugador). Tecla **B** o **tocar Alt** (pulsar y soltar sin rueda ni clics) = *Menú de Builder* (la tecla se cambia en Controles > LitBuild): herramientas, capabilities, Toolbox, Edit Block Attributes, cambio de modo de juego, velocidad de vuelo, Hotbar Swapper, Colour Picker y Gradient Helper. Mientras no actives nada, el juego se comporta como siempre. Lo implementan mixins sobre los clics del ratón, la rueda y el alcance (`MixinMinecraft`, `MixinInventoryPlayer`, `MixinPlayerControllerMP`); si no se aplican, el juego sigue normal y simplemente no actúan |
| Builder Tools | **Move**, **Clone**, **Stack**, **Smear**, **Extrude**, **Erase** y **Setup Symmetry**. Se eligen en el menú o con **Alt + rueda** (la lista sale en pantalla). Comparten la selección del editor. Clic izquierdo = 1ª esquina, derecho = 2ª esquina (el clic central selecciona un bloque, y más clics centrales o la rueda ya empujan); después la **rueda empuja** el destino 1 bloque hacia donde miras (**X / Y / Z** fijan el eje), el **clic central** lleva la esquina de la selección al bloque apuntado y el **derecho confirma**.
